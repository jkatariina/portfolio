# Portfolio — Jenna Virtanen

A personal portfolio built with React, Vite and React Router. Five pages:
home, project case studies, about, contact and a 404. No backend.

## Run it

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build into dist/
```

## Deploying

Pushing to `main` builds and deploys to GitHub Pages automatically
(`.github/workflows/deploy.yml`). Live at
https://jkatariina.github.io/portfolio/
