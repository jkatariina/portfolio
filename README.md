# Portfolio — Jenna Virtanen

A personal portfolio built with React, Vite and React Router. Five pages:
home, project case studies, about, contact and a 404. No backend.

## Run it

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build into dist/
```

## Deploying

Build command `npm run build`, publish directory `dist`. `public/_redirects`
handles client-side routes on Netlify.
